# Интернет-магазин отопительного оборудования «Михаил Потапыч»
## ООО «МП ТЕРРИТОРИЯ ТЕПЛА» (territoriatepla.ru)

Веб-платформа интернет-магазина отопительного оборудования, печей, котлов и систем монтажа.

---

## 🛡️ Безопасность и конфиденциальность (152-ФЗ, ЗоЗПП РФ)
1. **Изоляция конфигурации и секретов:**
   * Доступы к базе данных вынесены в `includes/config.local.php` (файл в `.gitignore`, не отслеживается репозиторием).
   * Для локальной разработки используйте шаблон `includes/config.example.php`.
   * Подавлен публичный вывод системных ошибок PDO в production.
2. **Защита персональных данных (152-ФЗ):**
   * Все публичные дампы базы данных обезличены (`schema.sql` содержит только структуру и каталог товаров, реальные данные пользователей исключены).
   * Активные чекбоксы согласия на обработку ПДн на формах регистрации (`register.php`, `auth.php`), оформления заказа (`checkout.php`) и контактов (`contacts.php`).
   * Внедрен Cookie-баннер согласия с фиксацией в `localStorage`.
   * Доступны официальные документы: Политика обработки персональных данных (`docs/personal_data_agreement.pdf`) и Публичная оферта / Пользовательское соглашение (`terms.php`).
3. **Безопасность веб-сервера (.htaccess):**
   * Запрещен листинг директорий (`Options -Indexes`).
   * Заблокирован доступ к скрытым файлам, дампам `.sql`, конфигам `.env`, `.local.php`, `.git`.
   * Подключены HTTP Security Headers (`X-Frame-Options`, `X-Content-Type-Options`, `Referrer-Policy`).

## 🚀 Установка и запуск
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/uffnv/mih.git
   cd mih
   ```
2. Создайте файл локальной конфигурации:
   ```bash
   cp includes/config.example.php includes/config.local.php
   ```
   Укажите параметры подключения к вашей локальной базе MySQL/MariaDB.
3. Импортируйте чистую схему базы данных:
   ```bash
   mysql -u root -p heating_equipment_store < schema.sql
   ```
4. Разверните проект на веб-сервере с поддержкой PHP 8.1+ и модулем `mod_rewrite`.
